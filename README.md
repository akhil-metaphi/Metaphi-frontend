# MetaPhi Frontend

Modern ERP and inventory management frontend built with React, Vite, and TypeScript.

## Features

- **Dashboard**: Overview of key business metrics and operations.
- **Master Module**: Category, Subcategory, Item, Unit, Supplier, Customer, GST, HSN, Labour, and Warehouse master records.
- **Warehouse Management**: Inward inventory management, dispatch tracking, and stock visibility.
- **User Management**: Granular role-based access control and user permissions.
- **Orders & Inventory**: Inventory levels, reorder tracking, and order workflows.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Routing**: React Router DOM
- **Linting**: Oxlint

## Getting Started

### Prerequisites

Ensure you have Node.js (v18+ recommended) installed.

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
